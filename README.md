## Featured Projects

### 1. Klingon — 认知输出与结构化日志系统

> A zero-setup, local-first **cognitive output & structured journaling system** — all in a single `index.html`.

基于**桦泽紫苑式输出法**（D1 直觉留痕 ➔ D3 转化书写 ➔ D7 沉淀实践），构成温和的 7 日记忆与沉淀闭环 —— a gentle 7-day loop from raw intuition to lasting practice.

- 晨间 3 件聚焦待办 · Morning 3-focus todo
- 杂志打孔票根式输出追踪 STUB 01/02/03 · Punch-card output tracker
- 晚思三行微复盘 · Three-line evening reflection
- 可打印 A4 月度生命星图双手账 · Printable A4 monthly star-map journal

**Design language** — 少即是多：单色调、零彩色 Emoji、无弹窗、温润纸白质感、克制的排版与微弱声音反馈。  
**Tech** — Pure HTML / CSS / JavaScript · localStorage · zero backend · zero account · 100% offline

### 2. Hawaii — IELTS 高分语块训练器

> A local-first **IELTS Band 8 collocation & muscle-memory training app** — "3 minutes a day".

将高粘性游戏化机制与严肃学习系统结合；从个人 Notion 学习笔记无缝同步，自动切片课时并提取语块。  
Combining sticky gamification with a serious learning engine — synced straight from your Notion notes.

- 选词积木 ➔ 盲打拼写 ➔ 原位掘空 · Three-stage mastery path
- Lv.0–4 艾宾浩斯间隔记忆引擎 · Ebbinghaus spaced-repetition engine
- Duolingo 式连胜打卡与里程碑印章 · Streak & milestone stamps

**Tech** — Next.js (App Router) · React · TypeScript · Tailwind CSS · Notion API · Web Audio API · Local-first storage
